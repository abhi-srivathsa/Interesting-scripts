# Interesting Scripts

A growing collection of fun, cool, and interesting scripts. Two new scripts are added every day!

## Categories

- **Games** - Terminal games and interactive fun
- **Utilities** - Handy tools and helpers
- **Art** - ASCII art, animations, and visual effects
- **Data** - Data generators, analyzers, and converters
- **Automation** - Scripts that automate tedious tasks

## Structure

Each script is self-contained and includes usage instructions in its header comment.
